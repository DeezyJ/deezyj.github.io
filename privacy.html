Privacy Policy

Pete Uploader · effective 2026-10-21

What Pete Uploader is

Pete Uploader is a private, single-user tool operated by Pete Fantasy FB. It uploads approved videos and their titles, descriptions and chapters to the Pete Fantasy FB YouTube channel using the YouTube Data API. It is not distributed to, installed by, or used on behalf of anyone other than the channel owner.

What data it uses

The tool signs in to one Google account, the channel owner's, through Google OAuth. Google grants it a token limited to uploading and managing videos on that channel. The tool stores that token on the owner's own private server and nowhere else. It does not read, collect or store any information about viewers, subscribers, commenters or any other person.

What it does not do

It does not sell, share or transfer any data to third parties. It does not use Google user data for advertising. It does not read email, contacts, files or any Google service other than the YouTube channel it publishes to. It sets no cookies and runs no analytics on this site.

Google API Services User Data Policy

Pete Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The channel owner can revoke the tool's access at any time at myaccount.google.com/permissions, which invalidates the stored token.
